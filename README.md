> Real-time Financial Market & Crypto Asset Tracker featuring interactive HTML5 Canvas charts, search filtering, and price alert thresholds.

---

## 🌟 Features

- **📊 Price Trends & Canvas Rendering**: High performance client-side canvas charting.
- **🔍 Asset Search**: Real-time asset filtering by symbol or company name.
- **🔔 Price Alert System**: Target threshold alerts for market movements.
- **🧪 Unit Tested**: Fully verified core market tracking logic.

---

## 🚀 Quick Start

```bash
git clone https://github.com/msyahirmahmud/crypto-stock-dashboard.git
cd crypto-stock-dashboard
npm start
```

Run unit tests:
```bash
npm test
```
